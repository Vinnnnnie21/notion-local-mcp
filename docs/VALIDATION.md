HTTP 验证使用脚本生成的临时配置、认证文件和演示项目，在空闲 loopback 端口启动本次源码。验证通过：

- 未认证的 `/health` 与 `/mcp` 返回 `401`；已认证请求可以初始化并读取版本。
- 实际发现 88 个工具，所有输入 schema 有效，包含 4 个诊断、保存与恢复工具。
- 演示文件读取和副本写入成功；数值代次源码保持可读，敏感字符串写入被拒绝且不出现在错误结果中。
- 有修改的副本在完成保存前不能关闭；保存成功后，相同请求查询得到同一任务，副本可以关闭，原项目不受副本写入影响。
